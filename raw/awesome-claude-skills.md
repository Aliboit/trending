### awesome-claude-skills — 精选 1000+ Claude Skills 资源与工具清单

**一句话总结**：精选 1000+ 生产级 Claude Skills 与插件，横跨 Claude.ai、Claude Code、Codex、Cursor 等 Agent 平台。

**解决什么问题**：Skills 资源分散在各处难以发现；该清单按用例系统整理，并附带 connect-apps 插件让 Claude 真正连接外部应用执行动作。

**核心亮点**
- connect-apps 插件通过 Composio 连接 500+ 应用（邮件/Issue/Slack 等）并处理鉴权
- 一行 `claude --plugin-dir` 安装，`/connect-apps:setup` 配置 API key 即用
- 覆盖 Claude.ai、Claude Code、Codex、Cursor、Gemini CLI、Antigravity 等多 Agent

**github链接地址**：https://github.com/ComposioHQ/awesome-claude-skills
