### ui-skills — 面向设计工程师的 UI 技能路由工具

**一句话总结**：面向设计工程师的 UI 技能集，通过 CLI 把 Agent 路由到合适的 UI 技能上。

**解决什么问题**：AI 编码 Agent 在处理 UI/设计任务时缺乏结构化的技能体系，难以匹配正确的实现范式。

**核心亮点**
- `npx ui-skills start` 一键路由 Agent 到对应 UI 技能集
- 支持分类浏览（categories）、按类列表（list --category）、获取技能（get）
- MIT 开源，配套 ui-skills.com 持续扩展

**github链接地址**：https://github.com/ibelick/ui-skills
