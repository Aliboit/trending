### 10. twenty — 开源 Salesforce 替代品

**一句话总结**：面向技术团队的开源 CRM，用代码定义对象/字段/视图，像管理代码一样管理 CRM，专为 AI 时代设计。

**解决什么问题**：传统 CRM 僵化难以定制，twenty 让开发团队用 Nx + React + NestJS 技术栈像构建应用一样构建 CRM。

**核心亮点**
- 代码即配置：TypeScript 定义对象模型，CLI 一键发布到工作区，支持版本控制
- 内置 AI Agent 框架、工作流引擎、视图系统和布局原语
- 提供云端版（twenty.com）和 Docker Compose 自托管方案，PostgreSQL + Redis 技术栈
