### text-to-cad — 面向 CAD、机器人和硬件设计的 Agent 技能库

**一句话总结**：面向 CAD、机器人和硬件设计的 Agent 技能库，支持从本地项目文件生成、检视、切片 CAD 与机器人描述文件。

**解决什么问题**：硬件设计与 CAD 工作流缺少专门的 AI Agent 技能，这个库补齐了生成、加工、机器人描述、仿真等环节的能力。

**核心亮点**
- 覆盖 CAD 生成/编辑、制造加工、机器人描述文件、仿真、本地审查等完整工作流
- 以 Agent 技能形式提供聚焦的工作流，而非通用大而全的工具
- 从本地项目文件直接操作，适配现有硬件设计流程
