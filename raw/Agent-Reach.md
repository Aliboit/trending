### Agent-Reach — 一行命令给 AI Agent 装上读遍全网的眼睛

**一句话总结**：一行命令给 AI Agent 装上读遍全网的眼睛。

**解决什么问题**：解决 Agent 想看 Twitter/Reddit/YouTube/小红书/B 站时被付费/封锁/登录/数据清洗各种门槛卡死的问题。

**核心亮点**
- 全部工具开源、API 免费，唯一可选成本是 $1/月代理
- 覆盖 Twitter、Reddit、YouTube、B 站、小红书、抖音、LinkedIn、微博、雪球等十几个平台
- 兼容 Claude Code/Cursor/Windsurf 等任意能跑 CLI 的 Agent
