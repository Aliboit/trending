### agent-native — Agent-Native 应用开源框架

**一句话总结**：一个让 UI 与自主代理共享状态、动作和协作体验的 agent-native 应用框架。

**解决什么问题**：许多 AI 应用在"人类可操作 UI"和"代理自动执行"之间割裂，状态不同步、上下文不一致；agent-native 让点击操作和自然语言指令成为同一系统的两种入口。

**核心亮点**
- 代理与 UI 共享同一数据库和状态，任一侧修改都可实时同步。
- 支持 CRDT 合并、实时 presence、多人协作和代理作为一等编辑者参与文档。
- 可运行在任意 SQL 数据库和任意托管环境，包括 serverless。

**github链接地址**：https://github.com/BuilderIO/agent-native
