# firecrawl/firecrawl

## 一句话总结
大规模搜索、抓取与交互 Web 的上下文 API，为 AI 代理提供干净可用的网页数据。

## 解决什么问题
AI 应用获取高质量网页内容难——JS 渲染、反爬、代理、速率限制等工程负担重。

## 核心亮点
- 覆盖 96% 的网页（含 JS 重度页面），P95 延迟 3.4s
- 输出干净 Markdown / 结构化 JSON / 截图，LLM 友好、省 token
- 自动处理代理轮换、编排、速率限制，零配置即可用
