### grok2api — 多账号 Grok API 网关

**一句话总结**：多账号 Grok API 网关，聚合 Grok Build、Grok Web 与 Grok Console 三个入口。

**解决什么问题**：用户需要在多个 Grok 入口间管理与轮换账号以提升可用性与并发能力；该项目提供统一网关将多账号多入口整合为标准 API 接口，便于下游应用接入。

**核心亮点**
- 同时支持 Grok Build、Grok Web、Grok Console 三种入口的多账号管理
- 标准化 API 输出，方便集成到聊天、工具、计费等下游平台
- 中英双语文档，附关联项目 DEEIX-Chat 轻量 AI 平台
