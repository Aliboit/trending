### claude-plugins-community — Claude 社区插件市场

**一句话总结**：Claude Cowork 与 Claude Code 的社区插件市场（只读镜像）。

**解决什么问题**：集中分发经审核的社区插件，让用户安全安装，同时保持 Anthropic 内部审查管道的唯一提交入口。

**核心亮点**
- 每晚从 Anthropic 内部审查管道同步，插件均通过自动化安全扫描
- 通过 `claude plugin marketplace add` 一条命令即可安装
- 提交统一走 claude.ai，直接对仓库开 PR 会被关闭

**github链接地址**：https://github.com/anthropics/claude-plugins-community
