### OpenLogi — 本地优先的 Logitech Options+ 开源替代品

**一句话总结**：用 Rust 编写的本地优先 Logitech Options+ 开源替代品。

**解决什么问题**：摆脱 Logitech Options+ 的账号绑定与遥测，通过 HID++/UVC 解锁鼠标、键盘、摄像头的完整能力。

**核心亮点**
- 原生 Rust + GPUI，轻量，Linux 是一等公民平台
- 支持任意按键绑定手势、DPI、SmartShift，纯 TOML 明文配置可跨设备同步
- 无账号、无遥测，支持 macOS / Linux / Windows

**github链接地址**：https://github.com/AprilNEA/OpenLogi
