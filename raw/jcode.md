# 1jehuang/jcode

**一句话总结**：一个用 Rust 打造、主打多会话与高性能的下一代编码 Agent 框架，把「技能天花板」往上抬。

**解决什么问题**：现有编码 Agent 在多会话并行、资源占用与可定制性上各有短板；jcode 把性能与可扩展性拉满，适配需要长时间、多任务并行的开发场景。

**核心亮点**：
- Rust 实现，单会话 RAM 占用与启动速度经优化显著低于同类
- 支持多会话工作流，可无限定制 Agent 行为与工作流
- 一键脚本安装（macOS/Linux/Windows），上手成本低

**GitHub 链接**：https://github.com/1jehuang/jcode
