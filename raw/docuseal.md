# docuseal

**一句话总结**：开源的 DocuSign 替代品，支持 PDF 表单创建、在线填写与电子签名，移动端优化。

**解决什么问题**：商业电子签名平台收费昂贵且数据不在自己手里，DocuSeal 提供可自托管的开源方案。

**核心亮点**：
- WYSIWYG 表单构建器，12 种字段类型（签名、日期、文件、复选框等）
- 自动 PDF eSignature + 签名验证，支持多提交者、SMTP 邮件、S3/GCS/Azure 存储
- API 与 Webhooks 集成，支持白标与用户角色，分钟级部署

**GitHub 链接**：https://github.com/docusealco/docuseal
