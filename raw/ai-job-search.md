### ai-job-search — 基于 Claude Code 的 AI 求职框架

**一句话总结**：把 Claude Code 变成全职求职助手，自动评估岗位匹配度、定制简历、写求职信并模拟面试。

**解决什么问题**：求职者面对海量招聘信息时难以高效筛选匹配岗位、反复手动改简历写求职信，耗时且容易遗漏关键信息。

**核心亮点**
- 自我画像 + 岗位匹配评估 + 起草-审阅双轨流水线，工作流语言与国家无关
- 内置丹麦主流招聘门户（Jobindex、Jobnet 等）搜索技能，可扩展到其它市场
- Fork 即用，填好个人资料即可让 Claude 全流程跑通

**github链接地址**：https://github.com/MadsLorentzen/ai-job-search
