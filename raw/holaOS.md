### holaOS — 开源 All-in-One AI Agent 工作区

**一句话总结**：开源 All-in-One AI Agent 工作区，可在同一本地优先环境中运行 Claude Code、Codex 等任意 Agent，共享记忆与 100+ 集成。

**解决什么问题**：不同 Agent 各有各的工具、上下文与配置，切换成本高。holaOS 让任意 Agent 在同一工作区共享同一份记忆、工具、技能和应用，无锁定。

**核心亮点**
- Claude Code、Codex、内置 holaOS Agent 并排运行，共享一切上下文与工具
- 100+ 集成与 MCP 支持，覆盖工具、应用、浏览器和文件
- 本地优先，内置前沿模型或自带 API Key（BYOK）

**github链接地址**：https://github.com/holaboss-ai/holaOS
