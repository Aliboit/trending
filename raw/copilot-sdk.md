### copilot-sdk — GitHub Copilot Agent 多语言 SDK

**一句话总结**：GitHub 官方多语言 SDK，将 Copilot Agent 的编排能力嵌入你自己的应用。

**解决什么问题**：想在自己的应用中集成 Copilot 的代理能力但不想自建编排引擎？Copilot SDK 暴露了与 Copilot CLI 同源的运行时，一行代码调用即可。

**核心亮点**
- 6 种语言 SDK（Python / TypeScript / Go / .NET / Java / Rust），统一 JSON-RPC 架构
- 自动管理 CLI 进程生命周期，支持 BYOK（自带 API Key）免 GitHub 订阅
- 代理自动处理规划、工具调用、文件编辑，开发者只需定义行为

**github链接地址**：https://github.com/github/copilot-sdk
