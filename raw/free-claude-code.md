### free-claude-code — 免费聚合编码智能体工具

**一句话总结**：免费聚合使用 Claude Code、Codex、Pi、OpenCode 等编码智能体的开源工具。

**解决什么问题**：解决单一编码智能体额度受限、供应商故障时无法续跑的问题，聚合 1.3B+ 免费 token 与 50 个合规供应商。

**核心亮点**
- 统一模型目录，一个可搜索 UI 管理免费/付费/订阅/本地模型，9 种编码智能体任选
- 供应商故障时自动切换到下一个已配置模型，无需重启对话，最多减少 90% 中断
- ToS 友好，严格遵循供应商条款并在不合规时移除集成
