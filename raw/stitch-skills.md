### stitch-skills — Google Stitch 的 Agent Skills 技能库

**一句话总结**：Google Stitch 的 Agent Skills 技能库，遵循 Agent Skills 开放标准，兼容多种编码代理。

**解决什么问题**：AI 编码代理（Codex、Claude Code、Cursor、Gemini CLI 等）各自独立，技能和插件难以复用。该项目遵循开放的 Agent Skills 标准，让同一套设计技能可以跨代理使用，降低重复开发成本。

**核心亮点**
- 遵循 Agent Skills 开放标准，兼容 Codex、Antigravity、Gemini CLI、Claude Code、Cursor 等主流工具
- 模块化设计：stitch-design（设计）、stitch-build（构建）、stitch-utilities（工具）可按需安装
- 支持 Codex 插件市场一键安装，提供 sparse checkout 加速克隆

**github链接地址**：https://github.com/google-labs-code/stitch-skills
