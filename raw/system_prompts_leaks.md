### system_prompts_leaks — AI系统提示词泄露合集

**一句话总结**：收录主流 AI 助手系统提示词的泄露与提取合集，持续更新。

**解决什么问题**：开发者、研究者难以了解各 AI 产品背后的真实系统指令，该仓库把 Claude、ChatGPT、Gemini、Grok、Cursor、Copilot 等的 system prompt 系统化整理出来。

**核心亮点**
- 覆盖 Anthropic、OpenAI、Google、xAI 等多家最新模型（Claude Fable 5、GPT-5.5 Codex、Gemini 3.5 Flash 等）
- 提供 Claude Opus 4.8 → Fable 5 的 diff 对比，可直观看到提示词演进
- 被《华盛顿邮报》引用，更新频繁、含 GitHub 链接便于追溯

**github链接地址**：https://github.com/asgeirtj/system_prompts_leaks
