# OpenCut

**一句话总结**：免费开源的跨平台视频编辑器，定位为 CapCut 的开源替代方案。

**解决什么问题**：商业视频编辑软件（如 CapCut）收费高、功能封闭、数据隐私不可控，用户需要一个真正自由、跨平台、可扩展的视频编辑工具。

**核心亮点**：
- 正在从零重写，采用 Rust 核心引擎，一套代码覆盖桌面、移动端和浏览器
- 插件优先架构，支持第三方插件；提供 Editor API 和 MCP server（AI Agent 可调用）
- 支持无头模式（自动化、批量渲染）和编辑器内脚本面板
