# santifer/career-ops

**一句话总结**：基于 Claude Code 的开源 AI 求职指挥中心，把任意 AI CLI 变成简历定制、岗位筛选、批量评估的流水线。

**解决什么问题**：公司用 AI 筛简历，求职者却在手工维护 Excel 跟踪应聘；该项目把流程反过来，让候选人用 AI 来挑公司。

**核心亮点**：
- 10 维加权 A-F 结构化评分系统，建议 4.0 以下直接放弃，避免无效投递
- 自动生成 ATS 友好且按 JD 定制的 PDF 简历
- 自动扫描 Greenhouse/Ashby/Lever 等主流招聘门户，支持 10+ 岗位并行子 Agent 评估

**GitHub 链接**：https://github.com/santifer/career-ops
