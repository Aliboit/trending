### FluidVoice — macOS 本地离线语音转文字听写应用

**一句话总结**：FluidVoice 是一款开源 macOS 离线听写应用，将语音识别与文本增强完全在本机完成，无需云服务或 API Key。

**解决什么问题**：云端语音转写会带来隐私、延迟和 API 成本问题；FluidVoice 将所有处理放在本地运行，语音数据不离开 Mac，适合注重隐私和即时输入的用户。

**核心亮点**
- 完全本地运行，无需云服务、API Key，语音数据不离开 Mac
- 新版 Parakeet 实现强调低延迟，接近说话即显示文字
- 支持 Homebrew 安装，提供本地 AI dictation enhancement 与主题优化

**github链接地址**：https://github.com/altic-dev/FluidVoice
