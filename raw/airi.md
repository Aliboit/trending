# airi

**一句话总结**：自托管的 AI 虚拟伴侣，灵感来自 Neuro-sama，支持实时语音聊天和游戏交互。

**解决什么问题**：虚拟主播/AI 伴侣领域缺少真正自托管、数据自主可控的开源方案，用户希望拥有一个可在本地运行、具备语音和游戏交互能力的 AI 角色。

**核心亮点**：
- 支持实时语音聊天，可在 Minecraft 和 Factorio 中玩游戏
- 覆盖 Web / macOS / Windows 多平台，支持 winget、Scoop、Homebrew 安装
- 完全自托管，用户拥有全部数据控制权

**GitHub 链接**：https://github.com/moeru-ai/airi
