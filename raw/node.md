### node — Node.js JavaScript 运行时，开源跨平台的服务端运行环境

**一句话总结**：Node.js JavaScript 运行时，由 OpenJS Foundation 支持维护，是全球最广泛使用的服务端 JavaScript 运行环境。

**解决什么问题**：为服务端 JavaScript 提供高性能运行时环境，支持非阻塞 I/O 和事件驱动架构，使 JavaScript 能够用于构建高性能的网络应用。

**核心亮点**
- 开源跨平台，由 OpenJS Foundation 提供支持
- 采用开放治理模型，社区驱动发展
- 提供 LTS 和 Current 两种发布渠道，满足不同稳定性需求

**github链接地址**：https://github.com/nodejs/node
