### DesktopCommanderMCP — Claude 终端控制与文件编辑 MCP 服务器

**一句话总结**：为 Claude 提供终端控制、文件系统搜索与差异编辑能力的 MCP 服务器，远超普通 AI 编辑器。

**解决什么问题**：Claude Desktop 等 AI 客户端缺少对终端和文件系统的深度控制能力。DesktopCommanderMCP 通过 MCP 协议赋予 AI 搜索文件、运行命令、差异编辑等能力，且使用宿主客户端订阅而非 API Token 计费。

**核心亮点**
- 终端控制 + 文件搜索 + 差异编辑三合一，功能超越多数 AI 编辑器
- 使用宿主订阅计费，无额外 API Token 成本
- 配套桌面 App（Beta）支持多模型（Claude/GPT-4.5/Gemini）与实时文件预览
