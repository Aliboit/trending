### goose — 通用型本地 AI 智能体

**一句话总结**：可装、可执行、可编辑、可测试的开源通用 AI 智能体（桌面 + CLI + API）。

**解决什么问题**：大多数编码助手只能"建议代码"，无法真正在用户机器上完成研究/写作/自动化/数据分析等端到端任务。

**核心亮点**
- 原生桌面 + CLI + API 三形态，Rust 编写跨平台高性能
- 兼容 15+ LLM 提供商，支持用现有 Claude/ChatGPT/Gemini 订阅（通过 ACP）
- 通过 MCP 接入 70+ 扩展，已加入 Linux 基金会下的 Agentic AI Foundation
