# graphify

**一句话总结**：将代码库、数据库 Schema、文档等转化为可查询知识图谱的 AI 编程技能。

**解决什么问题**：大型项目中开发者需要在海量文件间搜索理解代码关系，传统 grep 方式效率低下，需要一个将项目结构可视化为知识图谱的工具来提升理解效率。

**核心亮点**：
- 支持 Claude Code、Codex、OpenCode、Cursor、Gemini CLI 等主流 AI 编程助手
- 代码通过 tree-sitter AST 解析，完全本地化，无需 LLM，数据不外泄
- 将应用代码 + 数据库 Schema + 基础设施整合到一张图中统一查询

**GitHub 链接**：https://github.com/Graphify-Labs/graphify
