### pi-web — 为 pi 编码代理提供的本地 Web 工作区

**一句话总结**：为 pi 编码代理提供的本地 Web 工作区，读取本地会话文件，在浏览器里浏览会话、实时聊天、配置模型与管理技能。

**解决什么问题**：纯命令行使用 pi 代理时，结构化工具调用、会话回溯与结果查看体验不佳。Pi Web 把本地会话文件可视化，提供 Markdown 可读、会话浏览、模型配置、技能管理与项目文件预览的统一浏览器工作区，与 CLI 共享同一会话。

**核心亮点**
- 读取本地 pi 会话文件，CLI 与 Web 共享同一会话，结构化工具调用一目了然
- 支持实时聊天、模型配置、技能管理、项目文件预览
- 即开即用：`npx @agegr/pi-web@latest` 一行启动，端口/主机可配置

**github链接地址**：https://github.com/agegr/pi-web
