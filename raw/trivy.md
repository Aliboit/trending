# aquasecurity/trivy

**一句话总结：** 一站式安全扫描工具，覆盖容器、K8s、代码库和云环境中的漏洞、配置错误和密钥泄露。

**解决什么问题：** 现代云原生环境安全扫描碎片化，需要多个工具分别处理漏洞、配置和密钥检测。

**核心亮点：**
- 统一扫描器：同时检测 CVE、IaC 配置错误、敏感信息泄露和软件许可证合规
- 全覆盖目标：容器镜像、文件系统、Git 仓库、虚拟机、Kubernetes 集群
- 生态丰富：GitHub Actions、K8s Operator、VS Code 插件等深度集成

**GitHub 链接：** https://github.com/aquasecurity/trivy
