### claude-plugins-official — Anthropic 官方 Claude Code 插件目录

**一句话总结**：Anthropic 官方维护的 Claude Code 高质量插件精选目录，是用户发现、安装和管理插件的可信入口。

**解决什么问题**：Claude Code 用户缺少统一的插件发现和安装入口，容易接触来路不明的第三方插件带来安全风险；本项目提供官方+社区插件目录，区分内部维护和第三方插件，降低 MCP 与外部软件集成风险。

**核心亮点**
- 区分 Anthropic 内部维护插件和合作伙伴、社区第三方插件，方便用户评估信任边界。
- 支持通过 Claude Code 插件系统直接安装和浏览目录内容。
- 明确提示用户评估第三方插件风险，降低安全暴露面。

**github链接地址**：https://github.com/anthropics/claude-plugins-official
