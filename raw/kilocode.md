### kilocode — 覆盖多 IDE 的开源 AI 编码 Agent 平台

**一句话总结**：Kilo Code 是开源 AI 编码 Agent 平台，覆盖 VS Code、JetBrains 和 CLI，支持多模型开发体验。

**解决什么问题**：开发者在不同 IDE、终端和模型之间切换成本高，闭源工具价格和模型选择也常受限制；Kilo Code 提供统一入口和开放定价，让 AI 编码能力覆盖主要工作环境。

**核心亮点**
- 支持 VS Code、JetBrains 和 CLI，覆盖开发者主要工作流。
- 可选择 500+ 模型，并支持任务中途切换模型。
- 开源且主打零加价模型调用，降低 Agentic Engineering 使用门槛。

**github链接地址**：https://github.com/Kilo-Org/kilocode
