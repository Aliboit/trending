### claude-obsidian — Obsidian + Claude Code 的自组织 AI 第二大脑

**一句话总结**：把 Obsidian 与 Claude Code 结合的自组织 AI 第二大脑，将任意资料读入、链接、归档成你自己拥有的纯 Markdown 知识图谱。

**解决什么问题**：解决个人知识管理碎片化的问题，让笔记自动关联、可检索、可溯源，同时不放弃文件所有权。

**核心亮点**
- 基于 Karpathy 的 LLM Wiki 模式，将素材转为带引用来源的 Obsidian 页面
- local-first，vault 就是普通 Markdown/JSON 目录，不进插件缓存或云数据库
- 内置研究、检索、维护与可视化映射的显式工作流，越用越有用
