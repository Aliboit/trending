### tradingview-mcp — Claude Code 连本地 TradingView 做 AI 图表分析

**一句话总结**：通过 Chrome DevTools 协议把 Claude Code 连接到本地运行的 TradingView 桌面版，实现 AI 辅助图表分析与 Pine Script 开发。

**解决什么问题**：交易者希望用 AI 自动化分析 TradingView 图表、开发 Pine Script，但缺少本地安全连通方案，这个 MCP 桥解决了这个问题。

**核心亮点**
- 所有数据处理都在本地完成，不传输或存储任何 TradingView 数据
- 通过 Chrome DevTools 协议控制已运行的 TradingView 桌面应用，不绕过任何付费墙
- 适合个人工作流自动化，如图表分析、Pine Script 开发、流程自动化

**github链接地址**：https://github.com/tradesdontlie/tradingview-mcp
