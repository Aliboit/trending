### universal-android-debloater-next-generation — 非 root Android 设备预装应用清理工具

**一句话总结**：UAD-ng 是一个使用 ADB 清理非 root Android 设备预装应用的 Rust 跨平台 GUI 工具。

**解决什么问题**：Android 设备常带有难以卸载的厂商应用、运营商应用或可疑系统组件，影响隐私、安全、性能和续航；UAD-ng 帮助用户在无需 root 的情况下识别并禁用/移除不需要的应用。

**核心亮点**
- 不需要 root，基于 ADB 操作，覆盖更多普通用户设备。
- 目标是提升隐私、安全、速度、内存占用和电池续航。
- 提供 Wiki、使用指南和替代应用建议，强调风险提示与可控操作。
