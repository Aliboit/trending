### cua — Computer-Use Agent 的开源基础设施：沙箱、SDK、Benchmark

**一句话总结**：Computer-Use Agent 的开源基础设施：沙箱、SDK、Benchmark 一站式提供。

**解决什么问题**：训练/评估"会操作整台电脑"的 AI Agent 需要 macOS/Linux/Windows VM、驱动、评测集，自己搭一遍极其昂贵。

**核心亮点**
- Cua Drivers 后台操控桌面，不抢光标、不抢焦点
- 跨 macOS / Windows / Linux，可与 Claude Code、Cursor、Codex 等客户端集成
- 配套 Cua Bench 评测和 Lume macOS VM，覆盖训练到部署全链路

**github链接地址**：https://github.com/trycua/cua
