### cognee — AI Agent 长期记忆开源平台

**一句话总结**：为 AI Agent 提供持久长期记忆的开源平台，以自托管知识图谱引擎实现跨会话记忆与推理。

**解决什么问题**：AI Agent 缺乏跨会话的长期记忆，无法沉淀与关联历史上下文；Cognee 用可自托管的知识图谱让 Agent 具备真正的「长期记忆」。

**核心亮点**
- 支持任意格式数据摄入，持续构建自托管知识图谱
- 让每个 Agent 都能召回、关联、带着完整上下文行动
- 附带研究论文《优化知识图谱与 LLM 的接口以进行复杂推理》
