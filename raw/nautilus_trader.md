### nautilus_trader — 生产级 Rust 原生事件驱动量化交易引擎

**一句话总结**：生产级 Rust 原生多资产交易平台，采用确定性事件驱动架构。

**解决什么问题**：量化交易系统既要极致性能与安全性，又要策略开发的灵活性——NautilusTrader 用 Rust 编译引擎保证性能，用 Python 做策略控制面，两者兼得。

**核心亮点**
- 单一事件驱动架构覆盖研究、确定性回测仿真与实盘执行
- Rust 核心 + Python 控制平面的分层设计，兼顾性能与易用性
- 跨平台支持 Linux x86_64/ARM64、macOS ARM64、Windows

**github链接地址**：https://github.com/nautechsystems/nautilus_trader
