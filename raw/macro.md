### macro — 邮件/聊天/文档/任务/Agent/CRM 七合一工作区

**一句话总结**：一个将邮件、聊天、文档、任务、Agent、通话和 CRM 统一到单一界面并共享团队记忆的全能工作区。

**解决什么问题**：团队协作工具碎片化——Slack、Linear、Notion、HubSpot 各自为政，靠 MCP 和 Zapier 勉强缝合，公司知识无法计算。Macro 试图用一个系统替代所有，让数据 @link 互联、全员可搜。

**核心亮点**
- 团队级共享记忆，人与 Agent 无需切换工具即可获取完整上下文
- 邮件 + 消息 + 文档 + 任务 + Agent + CRM 七合一，全量 @link 互联可搜
- Rust 后端保证性能，面向初创团队"操作系统级"定位
