# xbtlin/ai-berkshire

**一句话总结**：AI Berkshire 将价值投资大师的方法论封装成 Claude Code 技能与多 Agent 研究框架。

**解决什么问题**：直接让通用 AI 分析股票往往会得到模糊、平衡但难以决策的结论；该项目把巴菲特、芒格、段永平、李录等投资方法结构化，引入多 Agent 并行研究和对抗分析，强调结论、纪律和研究深度。

**核心亮点**：
- 将价值投资流程拆解为可复用的 Claude Code Skill 合集。
- 使用多 Agent 并行和对抗式分析提升投资研究覆盖面。
- README 中提供实盘收益记录与方法论说明，强调框架来自真实投资实践。

**GitHub 链接**：https://github.com/xbtlin/ai-berkshire
