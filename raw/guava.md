### guava — Google Java 核心库

**一句话总结**：Google 官方 Java 核心库，提供集合、并发、I/O、缓存、图等基础工具，是 Java 生态基石。

**解决什么问题**：Java 标准库在集合类型、并发原语、缓存、字符串处理等方面存在缺口，开发者需要反复造轮子。

**核心亮点**
- 新增 Multimap、Multiset、ImmutableCollection 等集合类型，并含图库
- 覆盖并发、I/O、哈希、原语、字符串等工具，Google 内部几乎全量使用
- 提供 JRE 与 Android 两种 flavor，Maven 坐标 com.google.guava:guava

**github链接地址**：https://github.com/google/guava
