### flue — TypeScript 自治 Agent 与 AI 工作流框架

**一句话总结**：Flue 是一个 TypeScript Agent Harness 框架，用于构建自治 Agent 和可编程 AI 工作流。

**解决什么问题**：普通 SDK 往往只封装模型调用，难以组织可控、可验证、可暴露为服务的复杂 Agent 流程；Flue 通过 harness、技能和工具组合为 Agent 提供运行边界。

**核心亮点**
- 用 TypeScript 定义 Agent、路由、技能和工具，适合 Web/Node 生态集成。
- 支持将 Agent 暴露为 HTTP 服务，并为自动化任务提供上下文和自治能力。
- 强调 sandbox/harness 思路，帮助构建更安全、可组合的 AI 工作流。
