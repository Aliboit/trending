# PrismML-Eng/Bonsai-demo

**一句话总结**：在本地（Mac Metal / CUDA / Vulkan / ROCm / CPU）运行 Bonsai 1-bit 与 Ternary 量化大模型的演示仓库。

**解决什么问题**：1-bit / 三值量化等新型压缩大模型本地部署门槛高，缺乏开箱即用的运行示例。

**核心亮点**：
- 支持 Bonsai 27B（含视觉语言模型）、1-bit Bonsai 8B、Ternary-Bonsai 8B 全家族
- 27B 版支持图片/截图/PDF 视觉问答、原生 OpenAI 风格工具调用、MCP Server、256k+ 长上下文
- 跨平台覆盖 Mac/Linux/Windows/CPU，配套白皮书与 HF 模型集合
