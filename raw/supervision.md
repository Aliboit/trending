### supervision — 模型无关的计算机视觉"乐高积木"工具箱

**一句话总结**：把各种视觉模型变成可直接搭建应用的"乐高积木"工具集，一行 pip install 即用。

**解决什么问题**：开发者在不同检测/分割/分类模型之间反复造轮子（画框、跟踪、计数、ROI 区域统计），缺乏统一的模型无关工具层。

**核心亮点**
- 模型无关：对接 Ultralytics、Transformers、MMDetection、Inference、rfdetr 等主流框架
- 覆盖数据加载到实时区域计数的端到端工具链
- `pip install supervision` 即用，Python 3.9+

**github链接地址**：https://github.com/roboflow/supervision
