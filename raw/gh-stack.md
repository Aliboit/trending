### gh-stack — GitHub堆叠式分支与PR管理扩展

**一句话总结**：管理 GitHub 堆叠式分支与 PR 链的 gh CLI 扩展。

**解决什么问题**：将大改动拆成一系列小而可评审的 PR 链，并自动化分支创建、rebase、base 设置等繁琐维护。

**核心亮点**
- 自动处理 rebase、base 分支修正与层级导航
- 支持 AI agent 集成（`gh skill install`），让编码 Agent 理解 stacked PR
- 基于 gh CLI 扩展机制，一行命令安装

**github链接地址**：https://github.com/github/gh-stack
