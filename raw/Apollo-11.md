### Apollo-11 — 阿波罗11号制导计算机原始汇编源代码

**一句话总结**：阿波罗 11 号制导计算机（AGC）指令舱与登月舱的原始汇编源代码，数字化保存的历史级软件遗产。

**解决什么问题**：人类首次登月的核心软件遗产需要被保存与校对；该仓库由 Virtual AGC 与 MIT 博物馆数字化并持续维护。

**核心亮点**
- 包含 Comanche055（指令舱）与 Luminary099（登月舱）两套完整源码
- 30+ 语种 README 翻译，欢迎社区 PR 修正转录与原扫描差异
- 极具教育与历史价值，是软件工程的教科书级遗产
