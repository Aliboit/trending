# cwc-workshops

**一句话总结**：Anthropic 官方 Code with Claude 研讨会材料合集，含模型选型、多智能体分解、Claude Code 工作流等主题。

**解决什么问题**：开发者希望从官方视角学习如何用 Claude Code 与 MCP 构建真实生产级工作流。

**核心亮点**：
- rightmodel：用 SKILL 审计 LLM eval 套件，跨模型/推理参数扫描，找最优性价比
- agent-decomposition：把 400 行 prompt 的库存 agent 拆解为 skills + 代码执行 + callable_agents
- how-we-claude-code：三阶段 AI 辅助产品工作流（访谈→规格→多方案设计探索）

**GitHub 链接**：https://github.com/anthropics/cwc-workshops
