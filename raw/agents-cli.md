### agents-cli — Google Cloud Agent Platform 的 CLI 与技能集

**一句话总结**：agents-cli 为任意编码助手提供构建、评估和部署 Google Cloud 企业级 Agent 的命令与技能。

**解决什么问题**：在 Google Cloud 上构建企业级智能体涉及多种 CLI、服务和治理流程，agents-cli 将这些能力封装成可被 Claude Code、Codex、Antigravity 等编码助手调用的 skills 和命令，减少平台学习成本。

**核心亮点**
- 面向 Gemini Enterprise Agent Platform，提供构建、扩展、治理与优化智能体的工具链。
- 支持 uvx 安装完整 CLI，也可通过 npx skills add 只安装 skills。
- 兼容 Antigravity CLI、Claude Code、Codex 及其他编码代理。

**github链接地址**：https://github.com/google/agents-cli
