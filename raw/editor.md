### editor — 基于 WebGPU 的 3D 建筑编辑器

**一句话总结**：基于 React Three Fiber 和 WebGPU 构建的 3D 建筑编辑器，可在浏览器中创建和分享建筑项目。

**解决什么问题**：为建筑师和设计师提供一个在浏览器中直接创建、编辑 3D 建筑模型的开源工具，无需安装重型桌面软件。

**核心亮点**
- 采用 Turborepo monorepo 架构，将编辑器、查看器、核心模块分离为独立可复用包
- 基于 WebGPU 渲染，性能优异，支持复杂 3D 场景实时编辑
- 提供 npm 包发布体系，查看器运行时和节点定义可作为独立库集成到其他项目

**github链接地址**：https://github.com/pascalorg/editor
