### agent-skills — 面向 AI 编码代理的生产级工程技能集

**一句话总结**：把资深工程师的开发生命周期最佳实践打包成 AI 编码代理可遵循的可执行技能集。

**解决什么问题**：AI 编码代理在跨阶段（需求 → 设计 → 实现 → 测试 → 评审 → 发布）的工作中往往缺乏一致性与质量门禁，导致输出参差不齐。

**核心亮点**
- 提供 7 个斜杠命令（`/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship` 等），覆盖 DEFINE→PLAN→BUILD→VERIFY→REVIEW→SHIP 全流程
- 每个命令自动激活对应技能，强制"先 spec 再 code"的工程纪律
- 由 Addy Osmani 出品，面向 Claude Code 等主流 Agent 主机，开箱即用

**github链接地址**：https://github.com/addyosmani/agent-skills
