# refactoringhq/tolaria

**一句话总结**：跨平台 Markdown 知识库桌面应用，Files-first + Git-first，可承载万级笔记和 AI Agent 记忆库。

**解决什么问题**：Notion/Obsidian 等存在数据锁定或缺少原生 Git 工作流，AI Agent 难以稳定读写、版本管理也不够干净。

**核心亮点**：
- 原生 Markdown 文件，无需导出，任何编辑器可用，数据完全归属用户
- 每个 vault 即 Git 仓库，自带完整版本历史，支持任意 git remote
- 完全离线、无账号无订阅、开源；适合做"第二大脑"或 AI Agent 持久化记忆

**GitHub 链接**：https://github.com/refactoringhq/tolaria
