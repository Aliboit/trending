### book-to-skill — 将技术书籍 PDF 转为 Agent 技能

**一句话总结**：将技术书籍 PDF 转化为 Claude Code 可用的 Agent 技能，提取框架、决策规则和反模式。

**解决什么问题**：解决将整本书塞入上下文回答问题的低效问题——相比直接 dump，可节省 24×–51× 的 token 消耗。

**核心亮点**
- 三步流程：指定文件 → 蒸馏为技能结构（非摘要）→ 即查即用
- 生成框架、决策规则、反模式和逐章文件，结构化知识而非简单压缩
- 支持 GitHub Copilot CLI、Amp、Claude Code 等多种 Agent 工具
