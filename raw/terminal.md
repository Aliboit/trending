### terminal — Windows Terminal 与控制台主机源码仓库

**一句话总结**：Windows Terminal 与原版 Windows 控制台主机的官方源码仓库，提供现代终端体验。

**解决什么问题**：Windows 长期缺乏现代化、可定制、多标签的官方终端应用，开发者体验落后于 macOS/Linux。

**核心亮点**
- 将新 Windows Terminal 与原 Console Host 合并于同一仓库，统一维护
- 支持通过 Microsoft Store、winget、Chocolatey、Scoop 等多种方式安装，并提供 Canary 预览版
- 完善的开发者文档：构建指南（PowerShell/Cmd）、调试、编码规范、FAQ 一应俱全

**github链接地址**：https://github.com/microsoft/terminal
