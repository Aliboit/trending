### PowerToys — Windows 效率与定制工具集

**一句话总结**：微软官方给 Windows 重度用户的 30+ 实用小工具合集。

**解决什么问题**：Windows 默认体验在窗口管理、批量改名、键鼠定制、剪贴板增强等场景不够好，PowerToys 用一个安装包补齐这些「本应内置」的能力。

**核心亮点**
- FancyZones、PowerToys Run、PowerRename、Keyboard Manager 等明星工具
- 新增 Command Palette、Advanced Paste、Light Switch、ZoomIt 等
- 支持 GitHub 安装包、Microsoft Store、winget 多种发行渠道

**github链接地址**：https://github.com/microsoft/PowerToys
