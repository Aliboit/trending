### OpenViking — 自进化 AI Agent 上下文数据库

**一句话总结**：自进化的 AI Agent 上下文数据库，用虚拟文件系统统一记忆、知识 RAG 与技能。

**解决什么问题**：让 Agent 用 `ls`/`tree`/`find` 浏览自己的上下文，而非查询黑盒向量数据库。

**核心亮点**
- `viking://` 协议下以单一虚拟文件系统存储记忆、资源与技能
- 内容分 L0 抽象 / L1 概览 / L2 详情三层，按需加载
- 每次检索留下可观测、可调试的轨迹，并提供浏览器可直接打开的 Studio 演示

**github链接地址**：https://github.com/volcengine/OpenViking
