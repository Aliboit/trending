### GitNexus — 零服务端的代码智能引擎，把 Git 仓库变成交互式知识图谱

**一句话总结**：零服务端的代码智能引擎，纯浏览器端把任意 Git 仓库（GitHub/GitLab/Azure/本地/ZIP）构建成交互式知识图谱，并内置 Graph RAG Agent。

**解决什么问题**：AI Agent 理解大型代码库时容易「漏代码」；GitNexus 把每个依赖、调用链、集群与执行流都索引进知识图谱，再通过智能 MCP 工具暴露给 Agent，让它不再遗漏关键代码关系。

**核心亮点**
- 纯客户端运行、无需服务器，拖入仓库或 ZIP 即得交互式知识图谱
- 类比「比 DeepWiki 更深」：DeepWiki 帮你理解代码，GitNexus 让你分析代码——知识图谱追踪的是关系而非描述
- 内置 Graph RAG Agent + MCP 工具，让 AI Agent 不再漏掉代码
