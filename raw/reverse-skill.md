### reverse-skill — 网络安全技能路由包，AI 自动路由 + 按需自举工具链

**一句话总结**：面向 AI 编码客户端的网络安全技能路由包，让 Agent 遇到逆向/渗透任务时自动选择正确方法论和工具链。

**解决什么问题**：当 AI Agent 遇到 APK、二进制、前端 JS 加密、CTF 或渗透目标时，往往会"猜命令"而非按规范流程操作。这个技能包通过规则路由 + 工具自举 + 经验库，让 Agent 以可重复的工作流执行安全任务。

**核心亮点**
- 支持 Claude Code / Kiro / Cursor / Cline 等主流 AI 编码客户端
- 按需自举工具链：自动检测可用工具并引导安装，不预装冗余依赖
- 自进化经验库：执行过程记录到 timeline + Evidence，知识持续积累
