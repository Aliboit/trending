### AiToEarn — 一人公司 AI 内容营销与全平台分发变现智能体

**一句话总结**：面向"一人公司"的 AI 内容营销 + 全球 10+ 平台分发与变现智能体。

**解决什么问题**：创作者要在抖音/小红书/B 站/TikTok/YouTube/X 等十多个平台手动发布、互动、变现，工作量爆炸且难以接到商单。

**核心亮点**
- 四大 Agent 能力：Monetize（CPS/CPE/CPM 三种结算）/ Publish / Engage / Create
- 一键全网分发 + 日历排期，配套浏览器插件自动点赞/评论/品牌监测
- 提供 MCP 协议接入，可在 Claude / Cursor / OpenClaw 等 AI 助手内直接调用
