### Pumpkin — 用 Rust 全新打造的高速 Minecraft 服务器

**一句话总结**：用 Rust 从零打造的高性能 Minecraft 服务器，主打速度、效率与可定制。

**解决什么问题**：传统 Minecraft 服务器（如 Java 版）在性能与资源占用上存在瓶颈，插件扩展与安全防护也受限。Pumpkin 用 Rust 的多线程与内存安全重写服务器核心，在保持原版游戏机制的同时大幅提升吞吐与稳定性。

**核心亮点**
- 多线程架构榨取最大性能；兼容最新 Java 与 Bedrock 版本，遵循原版机制
- 安全优先，主动防御已知漏洞；高度可配置，可按需关闭特性
- 为插件开发提供坚实基础，采用 TOML 配置
