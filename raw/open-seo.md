# every-app/open-seo

**一句话总结**：OpenSEO 是一个开源 SEO 工具，主打可自托管、按量付费和可被 AI Agent 调用。

**解决什么问题**：Semrush、Ahrefs 等商业 SEO 平台价格高且功能臃肿，个人开发者和小团队常难以承担；OpenSEO 提供关键词、搜索数据、站点分析等 SEO 工作流，并通过 MCP 与 Agent skills 让 Claude Code、OpenClaw、Hermes 等工具参与 SEO 自动化。

**核心亮点**：
- 支持自托管，结合 DataForSEO、Google Search Console 等外部数据源。
- 提供 OpenSEO MCP 与预置 Agent skills，便于 AI Agent 执行 SEO 任务。
- 定位为免费加 API 成本的低门槛方案，适合可控预算和定制化需求。
