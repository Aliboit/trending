### CopilotKit — Agent 原生应用与生成式 UI 的全栈前端 SDK

**一句话总结**：构建 Agent 原生应用与生成式 UI 的全栈前端 SDK。

**解决什么问题**：解决 Agent 应用中 UI 渲染、状态同步、人机协作流程的工程化难题。

**核心亮点**
- AG-UI 协议作者，被 Google、LangChain、AWS、Microsoft 等采纳
- 支持 React/Angular/Vue/React Native，一套 Agent 通吃所有前端
- Generative UI + Shared State + Human-in-the-Loop 三件套开箱即用

**github链接地址**：https://github.com/CopilotKit/CopilotKit
