### bun — 极速 JavaScript/TypeScript 四合一工具包

**一句话总结**：一个用 Rust 编写的极速 JavaScript/TypeScript 运行时、打包器、测试运行器和包管理器，四合一工具包。

**解决什么问题**：Node.js 生态需要组合多个工具（运行时、打包器、测试框架、包管理器），启动慢、内存占用高。Bun 以单一可执行文件提供全部能力，大幅降低启动时间和内存消耗。

**核心亮点**
- 单个 `bun` 可执行文件替代 node + bundler + test runner + package manager
- 原生支持 TypeScript 和 JSX，开箱即用
- 与 Node.js 兼容，可在现有项目中几乎零改动使用
