### wigolo — AI Agent 的本地优先网络智能层，零成本联网

**一句话总结**：AI 编码 Agent 的本地优先网络智能层，搜索/抓取/爬取/研究零 API key、零云依赖。

**解决什么问题**：AI Agent 联网工具多依赖付费 API 与云端，成本高、隐私不可控，且与各类 Agent 客户端集成碎片化。

**核心亮点**
- 一个持久化表面覆盖 search/fetch/crawl/extract/cache/find-similar/research/自动 gather 循环
- 兼容 Claude Code、Cursor、Codex、Gemini CLI、VS Code、Windsurf、Zed 及 LangChain/CrewAI/LlamaIndex/n8n 等
- 全本地运行，数据不离开 ~/.wigolo/，$0/query，公测中
