# JCodesMore/ai-website-cloner-template

**一句话总结**：这个模板让 AI 编码 Agent 根据目标 URL 分析并重建网站，生成干净的 Next.js 项目。

**解决什么问题**：复刻一个网站通常需要手工分析布局、抽取设计 token、整理素材和实现组件；该模板通过 /clone-website 工作流指挥 AI Agent 检查页面、提取视觉规范、编写组件说明并并行构建各个区块。

**核心亮点**：
- 面向 Claude Code 等 AI 编码 Agent 设计，提供明确的网站克隆工作流。
- 自动化抽取设计 tokens、资产和组件规格，提升页面重建效率。
- 推荐以 GitHub template 方式创建独立项目，适合快速生成可维护的 Next.js 代码库。

**GitHub 链接**：https://github.com/JCodesMore/ai-website-cloner-template
