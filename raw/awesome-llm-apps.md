### awesome-llm-apps — 100+ 可直接运行的 AI Agent 与 RAG 应用模板

**一句话总结**：收录 100+ 可直接克隆、定制并部署的 AI Agent 与 RAG 应用模板合集。

**解决什么问题**：每次启动 LLM 项目都要从零搭建 RAG 管道、Agent 循环或 MCP 集成，重复劳动严重。该合集提供开箱即用的模板代码。

**核心亮点**
- 涵盖 AI Agents、常驻 Agent、多 Agent 团队、MCP Agents、RAG、语音 Agent 等多种类型
- 每个模板自包含完整源码，支持 Claude、Gemini、OpenAI、xAI、Qwen、Llama
- 提供分步教程，可直接 fork、定制并部署为生产级 LLM 应用
