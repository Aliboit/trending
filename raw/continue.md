### continue — 开源 AI 编码代理

**一句话总结**：一个开源编码代理项目，曾提供 CLI、VS Code 扩展和 JetBrains 插件。

**解决什么问题**：开发者需要在 IDE 和命令行中使用可定制、可配置的开源 AI 编码代理，而不是完全依赖封闭工具链。

**核心亮点**
- 支持 CLI、VS Code extension 和 JetBrains plugin 等多端形态
- 2.0.0 最终版本移除匿名遥测、抽离认证并修复多项问题
- 仓库已标注不再活跃维护且只读，后续使用需注意维护状态

**github链接地址**：https://github.com/continuedev/continue
