### OpenMAIC — 开放多智能体互动课堂，一句话生成整门课

**一句话总结**：Open Multi-Agent Interactive Classroom，一键获得沉浸式多智能体学习体验，一条 prompt 生成整门课程。

**解决什么问题**：把课程建设从繁琐制作变成「一句提示词出整门课」，并通过 agent 规划、构建、修订每一页，让学习体验更沉浸。

**核心亮点**
- v1.0.0 新增 Pro 工作台：对话式 agent 规划课程大纲、逐页构建与修订
- 持久化会话：服务端运行、重启不丢、可取消/恢复/随时调整
- 支持上传文档/音频/视频或联网搜索作为素材，agent 基于素材构建课程

**github链接地址**：https://github.com/THU-MAIC/OpenMAIC
