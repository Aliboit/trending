### skills — 实战 Agent 技能集

**一句话总结**：TypeScript 教育者 Matt Pocock 分享的实战 Agent 技能集，源自其 .agents 目录日常工程实践。

**解决什么问题**：市面上的 Agent 工作流框架过度接管流程、剥夺开发者控制权，且流程中的 bug 难以排查。

**核心亮点**
- 技能设计小巧、易修改、可组合，适配任意模型
- 基于数十年工程经验沉淀，专为"真正做工程"而非"vibe coding"而生
- 支持 Claude Code 插件化托管安装，也可手动复制自定义

**github链接地址**：https://github.com/mattpocock/skills
