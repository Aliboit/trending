# google/skills

**一句话总结**：Google 官方维护的 Agent Skills 仓库，覆盖 GCP 全家桶产品技术。

**解决什么问题**：AI Agent 调用 Google Cloud 服务时缺少标准化、官方背书的知识包，需要每个团队自行编写 Prompt 与流程。

**核心亮点**：
- 覆盖 Gemini API、AlloyDB、BigQuery、Cloud Run、GKE、Firebase 等核心服务
- 内置 Well-Architected Framework 六大支柱（安全/可靠/成本/卓越/性能/可持续）
- 通过 `npx skills add google/skills` 一键安装，可按需挑选具体 Skill

**GitHub 链接**：https://github.com/google/skills
