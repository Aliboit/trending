### ponytail — 让 AI agent 像最懒的资深工程师一样少写代码

**一句话总结**：让你的 AI agent 像团队里最懒的资深工程师一样思考——最好的代码是从没写过的代码。

**解决什么问题**：抑制 Agent 过度构建，实测平均少写 54%（最高 94%）代码、约省 20% 成本、快 27%。

**核心亮点**
- 在真实 Claude Code 会话中编辑真实开源仓库（FastAPI + React）测得，n=4、12 个特性任务
- 保留全部安全护栏，而裸的「写一行式」提示词会丢掉护栏
- 作者坦诚修正了此前 80-94% 的单次基准，给出更公平的每任务上限
