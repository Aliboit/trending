### TypeScript — JavaScript 的类型化超集

**一句话总结**：微软出品的 JavaScript 超集，为大规模 JavaScript 应用提供可选类型系统。

**解决什么问题**：JavaScript 缺乏类型系统，在大型应用开发中难以维护和重构。TypeScript 添加可选静态类型，支持任何浏览器、任何主机、任何操作系统，编译为可读的标准 JavaScript。

**核心亮点**
- JavaScript 的类型化超集，编译输出干净可读
- 支持大规模应用开发，工具链生态成熟
- 微软维护，社区活跃，npm 即可安装

**github链接地址**：https://github.com/microsoft/TypeScript
