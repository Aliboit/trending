### prisma — Node.js & TypeScript 下一代 ORM

**一句话总结**：Node.js 与 TypeScript 生态下一代 ORM，提供类型安全的查询构建器、声明式迁移与数据管理 GUI。

**解决什么问题**：传统 ORM 缺乏类型安全、迁移管理繁琐、数据查看编辑不便，开发者需要在不同工具间切换。

**核心亮点**
- Prisma Client 自动生成类型安全查询构建器，支持 PostgreSQL、MySQL、MariaDB、SQL Server、SQLite、MongoDB、CockroachDB
- Prisma Migrate 提供声明式数据建模与迁移系统
- Prisma Studio 提供 GUI 直观查看和编辑数据库数据

**github链接地址**：https://github.com/prisma/prisma
