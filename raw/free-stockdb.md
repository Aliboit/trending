### free-stockdb — A 股本地量化数据引擎

**一句话总结**：面向 A 股日K、分钟K与 ETF 数据的本地量化数据引擎，集成同步、缓存、复权、回测和指标计算。

**解决什么问题**：解决量化研究中全市场批量回测的数据工程瓶颈——远程 API 方案拉取全市场分钟数据需 3-5 天，而本地引擎可大幅提速。

**核心亮点**
- 数据本地落盘，增量同步、断点续传，Zstd 压缩传输
- 支持 Python / HTTP / Excel / HTML / MCP 五种调用方式
- 内置 39 种技术指标、5 种指数计算，自动处理停牌、退市、复权等数据清洗
