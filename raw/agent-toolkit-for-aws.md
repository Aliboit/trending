# aws/agent-toolkit-for-aws

**一句话总结**：Agent Toolkit for AWS 是 AWS 官方面向 AI 编码 Agent 的工具、知识与护栏集合。

**解决什么问题**：AI Agent 在云上开发时容易遇到服务选择、权限、成本、部署架构和最佳实践不稳定等问题；该工具包通过 MCP servers、skills 和插件，把 AWS 服务知识、CDK/CloudFormation、serverless、容器、存储、观测、计费和 SDK 使用纳入 Agent 工作流。

**核心亮点**：
- 官方支持，并兼容 Claude Code、Codex、Cursor、Kiro 等主流编码 Agent。
- 提供 aws-core 等插件，覆盖服务选择、部署、观测、成本和 SDK 指导。
- 通过工具与 guardrails 降低 AI Agent 操作 AWS 时的误用风险。

**GitHub 链接**：https://github.com/aws/agent-toolkit-for-aws
