# marketingskills

**一句话总结**：面向 AI Agent 的营销技能集合，覆盖 CRO、文案、SEO、分析和增长工程。

**解决什么问题**：技术型营销人员和创始人希望利用 AI 编程 Agent 来处理转化优化、文案撰写、SEO 等营销任务，但缺少专门为 Agent 设计的营销技能模块。

**核心亮点**：
- 覆盖 CRO（转化率优化）、文案撰写、SEO、分析、增长工程五大领域
- 兼容 Claude Code、OpenAI Codex、Cursor、Windsurf 等支持 Agent Skills 规范的工具
- 由营销领域专家 Corey Haines 构建，配套 Conversion Factory 机构和 AI Marketing Training 课程

**GitHub 链接**：https://github.com/coreyhaines31/marketingskills
