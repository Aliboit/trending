### prefect — Python 工作流编排框架，构建弹性数据管道

**一句话总结**：Python 工作流编排框架，用最少代码将脚本升级为生产级数据管道。

**解决什么问题**：数据团队需要将一次性脚本转化为具备调度、缓存、重试、事件驱动等能力的生产工作流，传统工具学习成本高、配置复杂。

**核心亮点**
- 几行代码即可实现调度、缓存、重试、依赖管理和复杂分支逻辑
- 支持自托管 Prefect Server 或托管版 Prefect Cloud 仪表盘监控
- 工作流可动态响应外部变化并从异常中自动恢复
