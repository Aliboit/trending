### claude-code-best-practice — 从 vibe coding 到 agentic engineering 的实践手册

**一句话总结**：一份系统化的 Claude Code 最佳实践集合，覆盖 agents、commands、skills、hooks、MCP、plugins 与配置，帮助用户从随意调用 AI 走向工程化 agent 工作流。

**解决什么问题**：Claude Code 功能模块众多（subagents、commands、skills、workflows、hooks、MCP servers、plugins、settings），用户缺少系统化示例和组织方式，容易停留在低效的「vibe coding」阶段。

**核心亮点**
- 汇总 subagents、commands、skills、workflows、hooks、MCP servers、plugins、settings 等关键概念并提供实践样例。
- 提供 `.claude/` 目录结构模板，可直接迁移到项目中。
- 强调从随意调用 AI 到工程化 agent 工作流的转变，适合进阶用户提升效率。
