### claude-code-templates — Claude Code 配置模板库

**一句话总结**：一套开箱即用的 Claude Code 配置模板库，涵盖 AI 代理、自定义命令、MCP 集成等。

**解决什么问题**：Anthropic 的 Claude Code 功能强大但配置繁琐，开发者需要从零搭建 agent、command、hook、MCP 等配置。该项目提供 100+ 预制模板，通过 `npx` 一键安装，大幅降低使用门槛。

**核心亮点**
- 提供 100+ 代理、命令、设置、Hook 和 MCP 模板，覆盖前端开发、代码审查、测试生成等场景
- 支持 `npx` 一键安装完整开发栈，也可交互式浏览选择
- 配套 Web Dashboard（aitmpl.com），可视化管理和追踪已安装组件

**github链接地址**：https://github.com/davila7/claude-code-templates
