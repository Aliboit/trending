### next.js — React 全栈框架，业界标杆

**一句话总结**：React 全栈框架，业界标杆，扩展最新 React 特性并集成 Rust 工具链实现最快构建。

**解决什么问题**：React 全栈应用构建涉及路由、SSR/SSG、数据获取、构建性能等复杂工程问题。Next.js 统一封装最新 React 特性与基于 Rust 的 JavaScript 工具链，提供全栈应用开发框架，被全球大量头部公司采用。

**核心亮点**
- 全栈能力：路由、渲染策略、API 路由、数据获取一体化
- 集成 Rust 工具链（SWC/Turbopack），构建速度极快
- 拥有完善的 Learn Next.js 课程与 Showcase，社区与文档成熟
