### insomnia — 开源跨平台多协议 API 客户端

**一句话总结**：Insomnia 是一个开源跨平台 API 设计、调试、测试与协作客户端。

**解决什么问题**：它帮助开发者在同一工具中处理 REST、GraphQL、WebSockets、SSE、gRPC 等 API 的调试、设计、测试和 CI/CD 集成。

**核心亮点**
- 支持多协议 API 调试，并内置 OpenAPI 编辑器和可视化预览。
- 提供测试套件、collection runner、mock server 和 Insomnia CLI。
- 支持本地、云端和 Git 存储，兼顾个人离线使用与团队协作。

**github链接地址**：https://github.com/Kong/insomnia
