### 10. revfactory/harness

**一句话总结**：一句话描述你的领域，自动生成 Claude Code 的 Agent 团队架构和专属技能。

**解决什么问题**：为复杂项目手动设计 Agent 团队费时且需要专业知识——Harness 用 6 种预定义团队模式（管道、扇出扇入、专家池等）自动编排代理。

**核心亮点**：
- 6 阶段工作流：领域分析 → 团队架构设计 → Agent 定义生成 → 技能生成 → 集成编排 → 验证测试
- 6 种架构模式覆盖不同场景：Pipeline、Fan-out/Fan-in、Expert Pool、Producer-Reviewer、Supervisor、Hierarchical Delegation
- 自动生成带渐进式披露（Progressive Disclosure）的技能文件，高效管理上下文窗口
