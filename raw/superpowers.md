### superpowers — 面向编码 Agent 的可组合技能框架与软件开发方法论

**一句话总结**：一套完整的软件开发方法论与可组合技能框架，让编码 Agent 从需求分析起就按结构化方法工作。

**解决什么问题**：编码 Agent 常直接跳进写代码、缺乏方法论约束；Superpowers 用一组可组合 skills + 初始指令，强制 Agent 在构建前先做规划与流程化操作。

**核心亮点**
- 方法论驱动：不只是工具集合，而是一套完整的软件开发方法论
- 广泛 Agent 支持：Claude Code、Antigravity、Codex、Cursor、Gemini CLI、Copilot CLI 等均可用
- 可组合 skills：技能模块化，按需启用
