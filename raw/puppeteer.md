### puppeteer — Chrome/Firefox 浏览器自动化 JavaScript API

**一句话总结**：Puppeteer 是用于自动化控制 Chrome 和 Firefox 的高层 JavaScript API。

**解决什么问题**：开发者需要对浏览器执行自动化操作，例如页面截图、PDF 生成、爬取、测试和性能诊断；Puppeteer 封装 DevTools Protocol 与 WebDriver BiDi，让脚本化浏览器控制更直接可靠。

**核心亮点**
- 默认支持无头浏览器运行，也可用于可视化调试。
- 覆盖页面导航、交互、截图、PDF、网络监控等常见自动化场景。
- 可选择完整安装自动下载浏览器，或使用 puppeteer-core 作为轻量库。

**github链接地址**：https://github.com/puppeteer/puppeteer
