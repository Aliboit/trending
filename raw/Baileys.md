# Baileys

## 一句话总结
基于 WebSocket 的 TypeScript 库，用于与 WhatsApp Web API 交互。

## 解决什么问题
WhatsApp 没有官方开放 API，开发者需要非官方手段实现消息自动化。Baileys 提供了一套类型安全、基于 WebSocket 的库来填补这一空白。

## 核心亮点
- 纯 TypeScript 实现，无需浏览器即可连接 WhatsApp Web
- 活跃的 Discord 社区和企业级支持选项
- 新版 7.0.0 带来多项改进，配套文档站点 baileys.wiki
