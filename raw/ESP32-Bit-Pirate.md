### ESP32-Bit-Pirate — ESP32 多协议硬件黑客工具，Web CLI 交互

**一句话总结**：ESP32 开源固件，将设备变为多协议硬件分析和开发工具，灵感来自 Bus Pirate，支持 Web CLI 交互。

**解决什么问题**：硬件黑客和嵌入式开发者需要 sniff/发送/脚本化多种数字协议（I2C、UART、SPI、1-Wire 等），传统工具昂贵且功能分散。ESP32 Bit Pirate 用一块廉价开发板 + 开源固件实现多协议分析。

**核心亮点**
- 支持 I2C/UART/SPI/1-Wire 等数字协议的 sniff/glitch/dump/slave 模式
- 兼容蓝牙、Wi-Fi、Sub-GHz、RFID 等无线协议
- USB 串口和 Web CLI 双交互方式，配有在线工具和硬件指南

**github链接地址**：https://github.com/geo-tp/ESP32-Bit-Pirate
