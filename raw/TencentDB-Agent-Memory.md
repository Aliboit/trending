### TencentDB-Agent-Memory — AI Agent 团队级记忆中枢

**一句话总结**：腾讯云出品的 AI Agent 团队级记忆中枢，将对话、文档和代码转化为四种可复用记忆资产。

**解决什么问题**：AI Agent 缺乏持久化、可治理、可跨框架共享的团队记忆能力。

**核心亮点**
- 四类记忆资产：Chat Memory、Skill、LLM-Wiki、Code-Graph，结构化管理
- 跨 Agent 和框架共享，一条命令启动 memory-core + memory-hub + proxy 全部服务
- 面板可视化（localhost:8125），支持 Proxy + Claude Code 直接使用

**github链接地址**：https://github.com/TencentCloud/TencentDB-Agent-Memory
