### nitter — 注重隐私与性能的替代 Twitter 前端

**一句话总结**：一个自由开源的替代 Twitter 前端，专注隐私与性能，灵感来自 Invidious。

**解决什么问题**：让用户在不被追踪、无广告、无 JavaScript 的前提下阅读 Twitter 内容。

**核心亮点**
- 所有请求经后端转发，客户端从不直接与 Twitter 通信，防止 IP 与指纹追踪
- 使用 Twitter 非官方 API，无需开发者账号
- 极轻量（60KB vs 784KB），近日收到 X Corp. 的停终信函，引发社区关注

**github链接地址**：https://github.com/zedeus/nitter
