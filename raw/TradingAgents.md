# TradingAgents

> 多智能体 LLM 金融交易框架

## 基本信息

- **仓库：** [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)
- **语言：** Python
- **今日 Star：** 299

## 解决什么问题

金融交易决策需要综合考虑基本面、情绪面、技术面、新闻面等多个维度，单一 LLM 难以全面评估。

## 核心亮点

- 角色分工：基本面分析师、情绪分析师、新闻分析师、技术分析师、交易员、风控团队协作决策
- 智能体间动态讨论，共同确定最优交易策略
- 支持 GPT-5.x / Gemini 3.x / Claude 4.x / Grok 4.x / DeepSeek 等多模型，提供回测与持久化决策日志

## 一句话总结

模拟真实交易公司架构的多智能体金融交易框架，从基本面到风控全链路协作。
