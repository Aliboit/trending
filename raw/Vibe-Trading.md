### Vibe-Trading — 个人交易 Agent 综合平台

**一句话总结**：Vibe-Trading 是一个为个人交易 Agent 提供数据、账户、工具调用与后端服务的统一平台，通过一条命令即可接入综合交易能力。

**解决什么问题**：个人量化、交易研究和自动化执行涉及数据、账户、工具调用、后端服务与跨平台运行等复杂组件；Vibe-Trading 把这些能力封装成 Agent 可用的统一工作流。

**核心亮点**
- 提供 Website、Docs、API/MCP、Shadow Account、Demo 与示例等完整入口
- 近期重点增强跨平台 setup/dev、运行时状态轮询、OAuth 缓存与文件工具隔离
- 面向交易 Agent 场景，兼顾开发、调试、账户连接和工具化调用
