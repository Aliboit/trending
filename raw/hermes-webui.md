### hermes-webui — Hermes Agent 的三栏式 Web 界面

**一句话总结**：为 Hermes Agent 打造的纯 Python+JS 三栏式 Web 界面，手机也能用。

**解决什么问题**：Hermes Agent 此前只能通过终端或消息应用交互，缺少一个可视化的 Web 管理界面，远程访问和移动端体验不佳。

**核心亮点**
- 与 CLI 功能完全对等——会话管理、文件浏览、技能调用全部可用
- 无构建步骤、无框架依赖，纯 Python+原生 JS 实现，一条命令启动
- 支持 SSH 隧道远程访问、Tailscale、手机端适配，内置主题切换和密码保护

**github链接地址**：https://github.com/nesquena/hermes-webui
