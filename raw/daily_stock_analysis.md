### daily_stock_analysis — LLM 驱动的多市场股票智能分析系统

**一句话总结**：基于大模型的多市场自选股智能分析与自动推送系统。

**解决什么问题**：为投资者或研究者自动聚合行情、新闻、技术指标和基本面信息，生成每日决策看板并推送到常用协作平台。

**核心亮点**
- 支持 A 股、港股、美股、ETF，以及部分日股/韩股数据边界下的行情与技术指标分析。
- 可生成核心结论、评分、趋势、买卖点位、风险警报、催化因素和操作检查清单。
- 支持 GitHub Actions、Docker、本地定时任务、FastAPI 和企业微信/飞书/Telegram/Discord/Slack/邮件推送。
