### GLM-5 — 智谱开源大语言模型系列

**一句话总结**：GLM-5 仓库集中发布 GLM-5、GLM-5.1、GLM-5.2 等模型信息，强调长上下文与智能体工程能力。

**解决什么问题**：复杂软件工程、长程任务和 Agent 工作流需要模型具备稳定长上下文、代码能力、可调推理强度和高效架构；GLM-5 系列面向这些需求持续迭代。

**核心亮点**
- GLM-5.2 强调 1M token 级长上下文能力，适合长程任务处理。
- 提供灵活 thinking effort，在性能与延迟之间做权衡。
- 介绍 IndexShare 等架构优化，并提供 API 平台与技术报告入口。
