# machine-learning-for-trading

> 《机器学习算法交易》第二版配套代码，150+ Notebook 覆盖从线性回归到深度强化学习。

## 解决什么问题

理论与实战脱节——了解 ML 算法却不知道如何将其落地为可回测、可评估的交易策略。

## 核心亮点

- 23 章、800+ 页配套 150+ 可运行 Notebook，覆盖数据获取、特征工程、策略回测全链路
- 从传统监督/无监督学习到 GAN 合成数据、深度强化学习交易 Agent，技术栈极全
- 包含市场数据、基本面数据、另类文本/图像数据的信号提取与实战案例
