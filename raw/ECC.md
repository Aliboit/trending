### ECC — Agent 性能优化系统（Anthropic 黑客松获奖项目）

**一句话总结**：一套完整的 Agent 优化操作系统，包含技能、本能、记忆持久化、安全扫描和研究驱动开发，182K+ stars。

**解决什么问题**：AI Agent 在长期使用中面临上下文丢失、Token 浪费、安全问题——ECC 提供从模型选择到并行编排的全链路优化。

**核心亮点**
- 跨 7 个 AI harness（Claude Code / Codex / Cursor / Gemini / Copilot 等），61 个 Agent + 246 个技能
- 记忆持久化：跨会话自动保存/加载上下文，持续学习：自动从会话中提炼可复用技能
- v2.0.0-rc.1 新增桌面仪表板 GUI、并行化工作流、12+ 语言生态支持
