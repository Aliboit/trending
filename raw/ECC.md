### ECC — AI 编程 Agent 性能优化系统

**一句话总结**：面向 AI 编程 Agent 的性能优化系统，为 Claude Code、Codex、Cursor 等提供技能、记忆和安全增强。

**解决什么问题**：提升 AI 编程助手的工作效率和安全性，通过技能系统、记忆管理和安全防护让 Agent 更可靠。

**核心亮点**
- 支持 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程工具
- 提供技能（Skills）、本能（Instincts）、记忆（Memory）、安全（Security）四大模块
- MIT 开源免费，同时提供 ECC Pro 托管 GitHub App 支持私有仓库
