### codex — 轻量级终端编码智能体

**一句话总结**：OpenAI 官方出品的轻量级终端编码智能体，可在本地运行。

**解决什么问题**：让开发者无需依赖云端的重型 IDE 插件，直接在终端里获得编码助手能力，同时支持在 VS Code、Cursor、Windsurf 等编辑器中使用。

**核心亮点**
- 提供 CLI、桌面 App、Web 以及 IDE 插件多种形态，覆盖不同使用场景
- 用 Rust 编写，安装便捷，一条 curl 命令即可完成 Mac/Linux 安装
- 官方发布源稳定，支持从 releases.openai.com 或 GitHub Releases 下载

**github链接地址**：https://github.com/openai/codex
