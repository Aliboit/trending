### gstack — Garry Tan 的 Claude Code 创业工具栈

**一句话总结**：gstack 是 Garry Tan 的 Claude Code 配置与工具集合，用一组带角色分工的工具帮助个人开发者像小团队一样交付。

**解决什么问题**：AI 编程能力增强后，个人开发者仍需要产品、设计、工程管理、发布、文档和 QA 等流程化支撑；gstack 将这些职责抽象为可调用的 agent 工具，降低 solo builder 的组织成本。

**核心亮点**
- 包含 23 个 opinionated tools，角色覆盖 CEO、Designer、Eng Manager、Release Manager、Doc Engineer、QA 等。
- 直接复用 Garry Tan 的 Claude Code 工作流经验，面向创业者和独立开发者。
- 强调从想法、设计、实现到发布的端到端 agent-assisted shipping。

**github链接地址**：https://github.com/garrytan/gstack
