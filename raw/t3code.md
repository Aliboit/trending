### t3code — 极简的编码 Agent Web GUI，一行命令启动多 Agent 工作台

**一句话总结**：极简的编码 Agent Web GUI，支持 Codex、Claude、Cursor 和 OpenCode 等多种 AI 编码工具，零安装一键启动。

**解决什么问题**：使用多种 AI 编码 Agent 时缺乏统一的图形界面，不同工具各自为政。T3 Code 提供一个轻量 Web GUI，无需安装即可通过 `npx t3@latest` 运行，也提供桌面应用。

**核心亮点**
- 多 Agent 支持：Codex、Claude、Cursor、OpenCode 开箱即用
- 零安装运行：`npx t3@latest` 即可启动，也提供桌面应用（winget/Homebrew/AUR）
- 极简设计，专注于编码 Agent 的核心交互体验

**github链接地址**：https://github.com/pingdotgg/t3code
