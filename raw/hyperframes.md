### hyperframes — Agent 友好的 HTML 转 MP4 视频框架

**一句话总结**：HyperFrames 是一个将 HTML、CSS、媒体和可寻址动画渲染为确定性 MP4 的开源视频框架，专为 agent 工作流设计。

**解决什么问题**：AI agent 生成视频时常缺少可验证、可预览、可重复渲染的工程化路径；HyperFrames 让视频制作转化为写 HTML 和动画代码，并通过 lint、preview、render 形成可控循环。

**核心亮点**
- 支持 CLI、本地使用和作为 hosted authoring workflow 的渲染核心。
- 提供 agent skills，指导 agent 完成规划、HTML 编写、动画接线、媒体添加、检查、预览和渲染。
- 输出确定性 MP4，适合产品介绍、营销视频和程序化视频生成。
