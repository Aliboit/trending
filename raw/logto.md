### logto — SaaS 与 AI 应用的身份基础设施

**一句话总结**：Logto 是一套面向 SaaS、AI 与 Agent 应用的开源认证授权平台，将登录、OIDC、多租户等能力产品化。

**解决什么问题**：生产级认证授权涉及 OIDC、OAuth 2.1、多租户、企业 SSO 与 RBAC 等复杂实现，自建容易出错且维护成本高，Logto 将这些能力打包为开箱即用的基础设施。

**核心亮点**
- 内置多租户、企业 SSO、RBAC、预构建登录流程和可定制 UI。
- 支持 OIDC、OAuth 2.1、SAML，并提供 30+ 框架 SDK。
- 面向 Model Context Protocol 与 Agent 型 AI 架构提供开箱即用支持。
