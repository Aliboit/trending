### ai-agent-book — 《深入理解 AI Agent》开源主仓库

**一句话总结**：李博杰所著《深入理解 AI Agent：设计原理与工程实践》的开源主仓库，提供全书正文、多语言 PDF 与按章配套实验代码。

**解决什么问题**：AI Agent 领域缺乏体系化的设计与工程实践教材，开发者难以从原理到实现完整理解 Agent 系统。

**核心亮点**
- 全书正文、配图与配套实验代码全部开源，支持中文/英文/泰米尔语/越南语多语言版本
- 提供从引言到第十章的完整正文源码，可使用 pandoc+xelatex 自行编译 PDF
- 每章配套可亲手运行的实验代码，鼓励提 issue 和 PR 参与共建

**github链接地址**：https://github.com/bojieli/ai-agent-book
