# phuryn/pm-skills

**一句话总结**：面向产品经理的 Agent Skill 市场，把 Teresa Torres、Marty Cagan 等方法论结构化封装。

**解决什么问题**：通用 AI 只给"文字"，缺乏 PM 工作所需的结构化框架（发现、假设映射、优先级、战略等）。

**核心亮点**：
- 68 个 PM 技能 + 42 个链式工作流，覆盖 discovery → strategy → launch → growth 全流程
- 提供斜杠命令入口（如 `/discover`、`/write-prd`、`/north-star`），上手即用
- 主打 Claude Code 与 Cowork，技能层兼容其他 AI 助手

**GitHub 链接**：https://github.com/phuryn/pm-skills
