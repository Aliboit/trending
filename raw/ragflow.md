### ragflow — 融合 RAG 与 Agent 的开源引擎

**一句话总结**：领先的开源 RAG 引擎，融合前沿 RAG 与 Agent 能力，为 LLM 打造优质上下文层。

**解决什么问题**：企业需要将复杂非结构化数据转化为高保真、生产级 AI 系统，但缺乏开箱即用的 RAG 工作流。RAGFlow 提供融合上下文引擎和预置 Agent 模板，适配任意规模企业。

**核心亮点**
- RAG + Agent 双引擎融合，预置 Agent 模板加速落地
- 融合上下文引擎，将复杂数据转化为高保真生产级 AI 系统
- 支持自托管和 Docker 部署，活跃社区与路线图

**github链接地址**：https://github.com/infiniflow/ragflow
