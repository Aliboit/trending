### htmx — 面向 HTML 的高能工具，用属性直接使用 AJAX/WebSocket

**一句话总结**：htmx 让 HTML 直接获得 AJAX、CSS 过渡、WebSocket 和 SSE 能力，用「超文本的简单与强大」构建现代 UI。

**解决什么问题**：打破 HTML 只能由 `<a>`/`<form>` 发起请求、只能 GET/POST、只能整屏替换的局限，补全 HTML 成为真正的超文本。

**核心亮点**
- 通过属性直接在 HTML 里使用 AJAX、CSS Transitions、WebSocket、SSE
- 极小（约 14k min.gz'd）、零依赖、可扩展
- 直接以 hypertext 的简洁方式构建现代用户界面

**github链接地址**：https://github.com/bigskysoftware/htmx
