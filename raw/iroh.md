### iroh — 公钥拨号 Rust 网络栈

**一句话总结**：一个让应用按公钥连接设备、自动寻找最快路径的 Rust 网络栈。

**解决什么问题**：现实网络中 IP 地址、NAT、移动设备和防火墙会让点对点连接不稳定，开发者往往需要处理复杂的打洞、relay 和连接维护逻辑。

**核心亮点**
- 以公钥作为拨号标识，屏蔽 IP 变化和网络位置差异
- 自动尝试直连和 NAT hole-punching，失败时回退到公共中继生态
- 基于 QUIC，天然支持认证加密、多路流、优先级和数据报传输
